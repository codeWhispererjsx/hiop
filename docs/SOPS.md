# Standard Operating Procedures

SOPs cover daily operations, weekly/monthly maintenance, emergencies, disaster recovery, security, guest technology support, network operations, server maintenance, and backup verification.

Procedures contain ordered Markdown sections, revisions, effective/expiry dates, review dates, and an optional mandatory acknowledgement. The lifecycle requires review before approval and publishing. Published procedures are immutable; changes are made as a reviewed revision.

Acknowledgements record the user, procedure version, and timestamp so compliance is tied to the exact effective text. Scheduled jobs identify due reviews and expired material. HIOP does not silently treat an expired or unacknowledged SOP as compliant.
