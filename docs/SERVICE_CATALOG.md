# Service Catalog

The service catalog describes hospitality technology services such as PMS, POS, Wi-Fi, PBX, CCTV, door locks, IPTV, directory, DNS, DHCP, Internet, storage, and virtualization.

Catalogs and items record property scope, technology-service linkage, description, availability objective, SLA summary, maintenance window, owner/support relationships, support hours, request templates, dependencies, documentation links, runbooks, SOPs, incidents, and assets through typed relationships.

Dependencies are explicit and self-dependencies are rejected. The catalog is descriptive: it does not automatically provision services or execute requests. Administrators manage catalog records; authorized operational users can read them.
