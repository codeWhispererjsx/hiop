# Discovery Network Topology

The Discovery Topology Viewer reads HIOP's reviewed topology graph. LLDP/CDP neighbor evidence, interfaces, VLANs, subnet and gateway relationships, uplinks, layers, WAN links, and confidence stay in the authoritative topology domain. Discovery Intelligence does not infer a link merely because two IP addresses share a subnet.

Nodes and links render as a keyboard-focusable SVG with an honest empty state. Detailed review, suppression, restoration, layout, and evidence operations remain available in Network Topology.
