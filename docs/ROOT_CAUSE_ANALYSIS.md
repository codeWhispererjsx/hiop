# Root Cause Analysis

The RCA workspace stores methodology, timeline reconstruction, technical findings, business findings, validation, causes, and contributing factors. Categories cover human, infrastructure, environment, process, vendor, and technology evidence.

The 5 Whys editor permits five ordered investigator-authored question/answer/evidence entries. The Fishbone editor records categorized possible causes. Possible causes do not become validated root causes implicitly. A cause must include a statement and evidence and must be explicitly marked validated before the Problem can advance.

No generative or probabilistic root-cause feature is present. All conclusions are deterministic records attributable to authenticated users.
