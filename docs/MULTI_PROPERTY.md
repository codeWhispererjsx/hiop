# Multi-Property Operations

HIOP resolves every cross-property request to an explicit set of permitted property UUIDs. Shared vendors and property-neutral contracts remain visible where appropriate, while incidents, assets, changes, settings, dashboards, search, and compliance are constrained to active property scopes. Scope evaluation is deterministic and auditable; no automated operational decisions are made.

The hierarchy uses existing organizations and properties, adding regions, countries, groups, clusters, offices, and property memberships. Business units support parent references and materialized depth/path values for unlimited organizational nesting.
