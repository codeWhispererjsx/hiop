# CMDB Impact Analysis

Impact analysis traverses reviewed dependency relationships to a bounded depth. Results distinguish direct and indirect potentially affected CIs, cycles, and linked change, incident, and knowledge evidence. Criticality and relationship reach determine a simple explainable risk label.

Impact output always states that it is deterministic relationship analysis rather than a guaranteed outage prediction. It does not execute a change, block a workflow automatically, or invent missing dependencies. Use the result as evidence during RFC review.
