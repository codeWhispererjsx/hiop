# Troubleshooting Center

Troubleshooting guides organize symptoms, problem signatures, severity, affected services, ordered resolution steps, verification, escalation criteria, known issues, and reviewed workarounds.

Guides are property-aware and searchable. Resolution content is deterministic documentation; it does not run commands or make network calls. Known issues preserve root cause and vendor references, while workarounds state limitations and verification status.

Operational relationships can connect guides to incidents, problems, devices, services, documents, maintenance, changes, vendors, locations, and tickets. Broken-link maintenance validates knowledge-owned targets without deleting historical evidence.
